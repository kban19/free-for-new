# تطبيق Kurmanji-TTS (نسخة سطح المكتب)

تطبيق سطح مكتب احترافي لتحويل النص المكتوب باللغة الكردية الكورمانجية (**Kurmanji - أبجدية Hawar اللاتينية**) إلى كلام صوتي طبيعي (**Text-to-Speech**) يعمل محلياً بالكامل دون الحاجة إلى اتصال بالإنترنت أو بطاقة رسوميات (GPU).

> **بيئة مُختبرة فعلياً (2026-11-20 على Windows 11):** Python 3.12.11، Flet 0.86.5، Piper CLI 2023.11.14-2، sherpa-onnx 2.0.1، نموذج `atenax/kurmanci-tts-piper` (MIT، 73.65 MB، 22050 Hz، 90 متحدثاً، المتحدث الموصى به 54). الاختبارات الآلية **34/34** نجحت، واختبار المحرك الحقيقي أنتج ملفات صوتية سليمة في الأنماط الثلاثة.

---

## 1. المميزات الرئيسية
* **عمل محلي كامل (100% Offline):** يعمل على المعالج المركزي (**CPU**) دون أي اعتماد على السحابة أو الإنترنت بعد التجهيز الأولي.
* **واجهة رسومية حديثة (Material Design 3):** مبنية بإطار **Flet** وتدعم الوضع الداكن والفاتح، واختيار المتحدث (مع اعتماد `Speaker 54` كافتراضي)، والتحكم بسرعة النطق (من `0.50x` إلى `1.50x`؛ الأعلى أسرع، مع تحويلها داخلياً إلى `length_scale = 1 / speed`).
* **معالجة دقيقة للأبجدية الكورمانجية (Unicode NFC):** حماية وتطبيع الحروف الكورمانجية الخاصة (`Ç ç Ê ê Î î Ş ş Û û X x W w`) لمنع تشوّه النطق عند النسخ واللصق.
* **أداء عالٍ دون تجميد الواجهة:** إبقاء النموذج محمّلاً في الذاكرة لتسريع التوليد المتكرر، وتنفيذ المعالجة في خيط خلفي (`asyncio.to_thread`).
* **تصدير صوتي عالي الجودة:** تشغيل مباشر داخل التطبيق مع إمكانية حفظ الصوت بصيغة **WAV** قياسية.
* **مشغل صوتي مدمج بالكامل (In-Process):** يعتمد على `winmm/MCI` على Windows و`aplay` على Linux، دون أي مشغل خارجي ودون إضافات Flet — يعمل فوراً داخل ملف `Kurmanji-TTS.exe` مع شريط تقدم لحظي (تحديث كل 100 ms) وإيقاف تلقائي عند نهاية المقطع.
* **أسماء متحدثين واضحة:** يقرأ `models/speaker_metadata.json` لعرض نوع الصوت (M/F/U) وإشارة المتحدث الافتراضي ★ بدلاً من معرّفات التجزئة.
* **طبقة تهيئة صوتية دون إعادة تدريب:** يحوّل الأرقام والنسب المئوية إلى كلمات كورمانجية، ويهجّي الاختصارات (`PDF` → `pî dî ef`)، ويطبّق قاموس `models/pronunciation_dict.json` القابل للتعديل مباشرة (بدون إعادة بناء `.exe`)، مع إبقاء النص المعروض كما كتبه المستخدم.
* **واجهة متعددة اللغات:** العربية (RTL) وKurdî Kurmancî وEnglish (LTR) مع مبدّل فوري في الشريط العلوي وحفظ الاختيار في `settings.json`، مع عزل اتجاهي للأرقام والوحدات.

## 3. طريقة التثبيت والتشغيل (خطوة بخطوة)

### الخطوة 1: إنشاء البيئة الافتراضية وتثبيت الاعتماديات

تأكد من تثبيت **Python 3.10** أو أحدث، ثم نفّذ الأوامر التالية في الطرفية:

**على Windows (PowerShell / CMD):**

```bat
python -m venv .venv
.venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

**على Linux (Ubuntu 22.04+):**

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip libgtk-3-0 libmpv2 gstreamer1.0-plugins-good
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### الخطوة 2: تنزيل محرك Piper والنموذج الكورمانجي (`atenax/kurmanci-tts-piper`)

أثناء الاتصال بالإنترنت لمرة واحدة فقط، شغّل أداة الإعداد التلقائية:

```bash
python setup_runtime.py
```

ستقوم الأداة تلقائياً بتنزيل:

1. محرك **Piper CLI** الرسمي المناسب لنظام التشغيل ووضعه داخل مجلد `piper/`.
2. ملفي النموذج الصوتي (`.onnx` و `.onnx.json`) من مستودع `atenax/kurmanci-tts-piper` ووضعهما داخل مجلد `models/` والتحقق من وجود `Speaker 54`.

### الخطوة 3: تشغيل التطبيق

```bash
python main.py
```

بعد إتمام الخطوة 2، يمكنك فصل الإنترنت تماماً وسيعمل التطبيق بكامل ميزاته دون اتصال.

## 4. طريقة الاستخدام

1. اكتب أو الصق النص الكورمانجي في مربع الإدخال (أو اختر أحد الأمثلة السريعة).
2. راقب عداد الأحرف والكلمات وحروف Hawar الخاصة المكتشفة.
3. اختر المتحدث المطلوب من قائمة **المتحدث (Speaker)** واضبط سرعة النطق إذا رغبت.
4. اضغط على زر **توليد الصوت (Generate Speech)**.
5. استمع إلى النتيجة عبر أزرار **تشغيل / إيقاف مؤقت / إيقاف**، أو اضغط **حفظ WAV** لتصدير الملف.

## 5. بناء نسخة تنفيذية مستقلة (Standalone Build)

### بناء نسخة Windows:

```bat
scripts\build_windows.bat
```

ستجد التطبيق النهائي داخل المجلد `dist/`، وسيقوم السكريبت تلقائياً بنسخ مجلدي `models/` و `piper/` وملف `THIRD-PARTY-LICENSES.md` بجانب الملف التنفيذي. (للبناء غير التفاعلي عيّن المتغير `KURMANJI_NO_PAUSE=1`؛ السكريبت يضبط `SSL_CERT_FILE` تلقائياً من certifi).

### بناء نسخة Linux:

```bash
chmod +x scripts/build_linux.sh
./scripts/build_linux.sh
```

## 6. حل المشكلات الشائعة

* **رسالة "محرك Piper غير موجود" أو "ملفات النموذج مفقودة":**
تأكد من تشغيل `python setup_runtime.py` أو افتح أيقونة **الإعدادات (⚙)** داخل التطبيق وحدد المسار الصحيح لملف `.onnx` وملف `piper`.
* **عدم عمل مشغل الصوت الداخلي على بعض توزيعات Linux:**
ثبّت حزم الوسائط `sudo apt install -y gstreamer1.0-plugins-base gstreamer1.0-plugins-good libmpv2`. وفي حال عدم توفرها، يقوم التطبيق تلقائياً بفتح الملف الصوتي عبر مشغل النظام الافتراضي.
* **بطء أول عملية توليد فقط:**
في أول مرة يتم تحميل أوزان الشبكة العصبية إلى الذاكرة العشوائية (RAM). بفضل تفعيل خيار **إبقاء النموذج محمّلاً في الذاكرة** في الإعدادات، ستكون العمليات التالية فورية تقريباً.
